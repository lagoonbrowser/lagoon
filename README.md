# Lagoon

A calm web browser for Mac. Built on Chromium, with Liquid Glass, profiles, a built-in blocker and Chrome extensions.

**Download:** [Lagoon.dmg](https://github.com/lagoonbrowser/lagoon/releases/latest/download/Lagoon.dmg) · Website: [lagoonbrowser.com](https://www.lagoonbrowser.com/)

Requires macOS 26 or later on a Mac with Apple silicon.

## Install

1. Open `Lagoon.dmg` and drag Lagoon into your Applications folder.
2. Lagoon is not notarized by Apple yet. On the first launch macOS blocks it: open **System Settings › Privacy & Security** and click **Open Anyway** next to Lagoon. You only have to do this once.
